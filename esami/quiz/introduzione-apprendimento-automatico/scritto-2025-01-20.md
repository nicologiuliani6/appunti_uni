## [mcq 1] Nel caso di un albero di decisione con features discrete, cosa si può dire della profondità dell'albero?
- [x] E' minore o uguale al mumero delle features 
- [ ] E' sicuramente maggiore del logaritmo in base due del numero dei dati
- [ ] E' minore o uguale del numero delle classi
- [ ] Non si può dire nulla

### Soluzione
Con features discrete ogni feature si testa al più una volta per cammino (dopo il test il valore è fissato), quindi la profondità ≤ numero di features.

## [mcq 1] Un dataset contiene 1/3 di positivi e 2/3 di negativi. La recall del modello è di 2/3. Che percentuale dei dati sono Falsi Negativi?
- [ ] Non può essere stabilito
- [ ] 1/3
- [x] 1/9 
- [ ] 2/9

### Soluzione
Positivi = 1/3, recall = TP/P = 2/3 ⇒ TP = 2/9 e FN = 1/3 − 2/9 = **1/9**.

## [mcq 1] Selezionare la sentenza ERRATA relativa alla probalità condizionata P(A|B) tra due eventi A e B
- [ ] P(A|B) può essere maggiore di P(A)
- [ ] P(A|B) può essere inferiore a P(A)
- [x] P(A|B) è sicuramente minore o uguale di P(A and B)
- [ ] P(A|B) è sicuramente maggiore o uguale di P(A and B) 

### Soluzione
$P(A|B)=P(A\wedge B)/P(B)$ e $P(B)\le1$ ⇒ $P(A|B)\ge P(A\wedge B)$. Rispetto a $P(A)$ può essere sia maggiore che minore.

## [mcq 1] Il problema della scomparsa del gradiente (vanishing gradient) si riferisce a una progressiva diminuzione dell'intensità del gradiente, dovuta a

- [ ] dati troppo rumorosi o malamente preprocessati
- [ ] troppi pochi dati di training a disposizione

## [mcq 1] Selezionare la sentenza SCORRETTA relativa alle Generative Adversarial Networks
