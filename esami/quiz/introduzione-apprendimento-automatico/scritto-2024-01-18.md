## [mcq 1] Selezionare la sentenza corretta riguardo agli alberi di decisione
- [x] Possono espimere qualunque funzione di classificazione
- [ ] Non presentano problemi di overfitting
- [ ] Possono essere utilizzati solo con features discrete
- [ ] Il costo computazionale della predizione è piuttosto elevato

### Soluzione
Un albero abbastanza profondo partiziona lo spazio in regioni arbitrarie: può esprimere qualunque funzione di classificazione (proprio per questo va in overfitting). La predizione costa O(profondità), quindi è economica.

## [mcq 1] Selezionare la sentenza ERRATA relativa all'entropia per la distribuzione di probabilità di una variabile aleatoria discreta
- [ ] è una misura del grado di disordine della variabile aleatoria
- [ ] Il range del suo valore è tra 0 e log n dove n sono i possibili valori di X
- [ ] Il suo valore è minimo (e uguale a 0) quando la probabilità è tutta concentrata in una classe
- [x] Il suo valore è minimo (e uguale a 0) quando la probabilità è equamente distribuita tra tutte le classi

### Soluzione
L'entropia $H(X)=-\sum p_i\log p_i$ è **massima** ($\log n$) con distribuzione uniforme e **minima** (0) quando tutta la probabilità è su una classe.

## [mcq 1] Se un modello calcola una distribuzione di probabilità, aggiungere alla funzione obiettivo una componente tesa a diminuire l'entropia avrà l'effetto di:
- [ ] favorire l'uscita da minimi locali
- [ ] ridistribuire le probabilità in modo più bilanciato tra tutti i casi
- [ ] nessun effetto concreto
- [x] focalizzare le scelte sui casi più probabili

### Soluzione
Diminuire l'entropia spinge la distribuzione a concentrarsi: le scelte si focalizzano sui casi più probabili.

## [mcq 1] Selezionare la sentenza ERRATA relativa alla derivata della funzione logistica:
- [ ] tende a 0 quando x tende a meno infinito
- [x] è una funzione monotona
- [ ] ha il suo massimo in corrispondenza dello 0
- [ ] è una funzione simmetrica

### Soluzione
$\sigma'(x)=\sigma(x)(1-\sigma(x))$ è una campana: simmetrica, massimo 1/4 in 0, tende a 0 ai due estremi, quindi **non** è monotona.

## [mcq 1] Ci sono due dadi, uno normale e uno truccato che restituisce un 6 con probabilità .5, e gli altri valori con probabilità 0.1. Faccio tre lanci con lo stesso dado e osservo un 3, un 6 e un 2. Cosa posso concludere?
- [ ] E' più probabile che il dato sia normale
- [ ] Nulla
- [ ] La probabilità di usare uno o l'altro dei dadi è esattamente la stessa
- [x] E' più probabile che il dato sia truccato

### Soluzione
Verosimiglianze: normale $(1/6)^3 \approx 0.00463$; truccato $0.1\cdot0.5\cdot0.1 = 0.005$. Con prior uguali è (di poco) più probabile il dado truccato.

## [mcq 1] Un dataset contiene 1/3 di positivi e 2/3 di negativi. La recall del modello è di 2/3. Che percentuale dei dati sono Falsi Positivi?
- [ ] 1/3
- [ ] 1/9
- [x] Non può essere stabilito
- [ ] 2/9

### Soluzione
Recall $= TP/(TP+FN) = 2/3$ con positivi $=1/3$ → TP = 2/9, FN = 1/9. I falsi positivi dipendono dai **negativi** classificati male, su cui non si sa nulla: non determinabile.

## [mcq 1] Selezionare la sentenza SCORRETTA riguardo alla regressione logistica
- [ ] Permette di associare una probabilità alla predizione della classe
- [ ] Il calcolo della predizione si basa sulla loglikelihood dei dati di training
- [x] I parametri del modello possono essere tipicamente calcolati in forma chiusa, mediante una formula esplicita
- [ ] La predizione dipende dal bilanciamento dei dati di training rispetto alle classi

### Soluzione
La log-likelihood della regressione logistica non ha soluzione in forma chiusa (a differenza della regressione lineare): si ottimizza con discesa del gradiente.

## [mcq 1] Selezionare la sentenza SCORRETTA relativa alla tecnica a discesa del gradiente.
- [ ] Il risultato può dipendere dalla inizializzazione dei parametri del modello
- [ ] E' opportuno decrementare il learning rate verso la fine dell'apprendimento
- [ ] Potrebbe convergere a un minimo locale
- [x] Può essere applicata solo se la funzione da minimizzare ha una superficie concava

### Soluzione
La discesa del gradiente si applica a qualunque funzione differenziabile (anche non convessa, con il rischio di minimi locali). Nota: per una minimizzazione la forma 'buona' sarebbe convessa, non concava.

## [mcq 1] Quale è l'effetto tipico dell'aumento della dimensione del minibatch durante il training?
- [x] La Backpropagation è effettuata meno frequentemente ma l'aggiornamento dei parametri è più accurato
- [ ] La Backpropagation è effettuata più frequentemente e l'aggiornamento dei parametri è più accurato
- [ ] La Backpropagation è effettuata più frequentemente ma l'aggiornamento dei parametri è meno accurato
- [ ] La Backpropagation è effettuata meno frequentemente e l'aggiornamento dei parametri è meno accurato

### Soluzione

## [mcq 1] Riguardo alla regressione multinomiale, selezionare la sentenza corretta tra le seguenti
- [x] Il peso con cui è valutata ogni feature è tipicamente diverso per ogni classe
- [ ] Per n features di input e m classi, il numero dei parametri del modello cresce come O(n+m)
- [ ] Per ogni input, esiste almeno una classe con probabilità > 0.5
- [ ] I pesi delle features sono sempre tutti positivi, i bias possono essere negativi

### Soluzione
Ogni classe ha il suo vettore di pesi: matrice $n\times m$, parametri $O(n\cdot m)$. Con molte classi la probabilità massima può essere < 0.5; i pesi possono essere negativi.

## [mcq 1] Selezionare la sentenza corretta relativa alla funzione softmax
- [x] Restituisce una distribuzione di probabilità sulle classi
- [ ] Produce valori compresi nell'intervallo [-1,1]
- [ ] Per una data classe,  la somma dei valori su tutti gli input di un minibatch è sempre 1
- [ ] Non può essere utilizzata nel caso di una classificazione binaria

### Soluzione
Softmax $e^{z_i}/\sum_j e^{z_j}$: valori in (0,1) che sommano a 1 sulle classi (per ogni input, non sul minibatch). Con 2 classi equivale alla sigmoide.

## [mcq 1] In quale di questi casi una tecnica di classificazione lineare potrebbe non fornire risultati soddisfacenti:
- [ ] Quando esiste una elevata correlazione tra le features
- [ ] Quando non tutte le features di input sono rilevanti ai fini della classificazione
- [x] Quando la classificazione dipende da un confronto tra features
- [ ] Quando le features sono indipendenti tra loro, data la classe.

### Soluzione
Risposta ufficiale (c). Le relazioni tra features (es. XOR, uguaglianza, prodotti) non sono separabili linearmente; correlazione, features irrilevanti o indipendenti non sono un problema per un modello lineare.

## [mcq 1] Selezionare la sentenza corretta relativa alle tecniche discriminative
- [x] Si focalizzano sulla definizione delle frontiere di decisione (decision boundaries)
- [ ] Cercano di determinare le distribuzioni di probabilità delle varie classi di dati
- [ ] Sono tipicamente meno espressive delle tecniche generative

### Soluzione
Discriminativi modellano $P(y|x)$ o direttamente il decision boundary; i generativi modellano $P(x|y)$, la distribuzione delle classi.

## [mcq 1] Un layer convolutivo 2D con stride 1, kernel size 3x3, e senza padding prende in input un layer con dimensioni (32,32,3) e restituisce un layer di dimensione (32,32,16). Quanti sono i suoi parametri?
- [x] 448
- [ ] 432
- [ ] 28
- [ ] 160

### Soluzione
Parametri = $(3\cdot3\cdot3)\cdot16 + 16$ bias $= 432+16 = 448$. (Il testo dice 'senza padding' ma l'output 32×32 implica padding 'same': ai parametri non cambia nulla.)

## [mcq 1] Il tensore di input di un layer convolutivo 2D ha dimensione (16,16,32). Sintetizzo 8 kernel con dimensione spaziale (3,3), stride 2, nessun padding (valid mode). Quale sarà la dimensione dell'output?
- [x] (7,7,8)
- [ ] (8,8,32)
- [ ] (8,8,8)
- [ ] (7,7,15)

### Soluzione
Output spaziale $\lfloor (16-3)/2 \rfloor + 1 = 7$; canali = numero di kernel = 8 → (7,7,8).

## [mcq 1] Qual'è l'effetto di uno stride non unitario (>1) in un layer convolutivo?
- [ ] La dimensione spaziale aumenta
- [ ] Nessun effetto spaziale, il numero dei canali aumenta
- [x] La dimensione spaziale diminuisce
- [ ] Nessun effetto spaziale, il numero dei canali decresce

### Soluzione
Stride s > 1 riduce la dimensione spaziale di circa un fattore s (downsampling).
